## How to add yourself

1. **Open a PR** with whatever contribution you have — a new skill, a regulation update, a typo fix, a bug report follow-up, anything that helps the project.
2. **In your PR description**, add a line like:
   ```
   @all-contributors please add @<your-github-handle> for code, docs
   ```
   Use any combination of the emoji-key labels above (lowercased, comma-separated). Aliases: `code`, `design`, `doc`, `ideas`, `research`, `bug`, `review`, `translation`, `projectManagement`, `business`, `talk`, `infra`, `security`, `test`, `userTesting`, `financial`.
3. **A maintainer will update this file** before merging your PR so your contribution is permanently recorded.

If you'd rather add yourself manually, just include the table row edit in the same PR — that's also fine. Either way, the contribution is yours and we want it credited.

## Recognition policy

- **Every contribution counts.** A one-character typo fix gets the same first-time-contributor recognition as a 1,000-line vertical playbook.
- **Regulatory expertise is highly valued.** If you flag an outdated substance limit or a missing transition date, you go in with 🤔 — those reviews keep the library trustworthy.
- **No paid contributions required.** You don't need to be a Cleo Labs customer, partner, or contractor to be listed here. The list is for everyone who has materially helped the project.
- **You can opt out.** If you contributed but don't want to be listed, tell us in the PR or email contact@cleolabs.co and we'll respect that.
